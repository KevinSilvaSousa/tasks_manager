# tasks_manager
### Apresentação do projeto

Esse projeto ele é um gerenciador de tarefas, onde nós podemos criar, atualizar, verificar e deletar uma tarefa. Para rodar o projeto é necesario usar:

`python -m uvicorn src.main:app --reload`


### Objetivo

O objetivo do projeto é ajudar um usuário a nunca esquecer nenhuma tarefa, e sempre ser lembrado pela aplicação
